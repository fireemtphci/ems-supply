# 救護耗材管控系統 PWA

## 上傳到 GitHub Pages 步驟

### 1. 註冊 GitHub
前往 https://github.com 註冊免費帳號

### 2. 建立新 Repository
- 點右上角「+」→「New repository」
- Repository name 輸入：ems-supply（或任意名稱）
- 選「Public」
- 勾選「Add a README file」
- 按「Create repository」

### 3. 上傳檔案
- 點「Add file」→「Upload files」
- 將以下所有檔案拖曳上傳：
  - index.html
  - manifest.json
  - sw.js
  - icons 資料夾（含兩張圖示）
- 按「Commit changes」

### 4. 開啟 GitHub Pages
- 進入 Repository → 點上方「Settings」
- 左側選「Pages」
- Source 選「Deploy from a branch」
- Branch 選「main」，資料夾選「/(root)」
- 按「Save」
- 等 1～2 分鐘後，會出現您的網址（如：https://yourname.github.io/ems-supply）

### 5. 手機安裝
#### Android：
- 用 Chrome 開啟網址
- 點右上角選單「⋮」→「加到主畫面」
- 或等待底部自動出現「安裝」橫幅

#### iPhone（iOS）：
- 用 Safari 開啟網址
- 點底部「分享」按鈕（方形加箭頭圖示）
- 選「加入主畫面」
- 按「新增」

完成！桌面會出現 APP 圖示，點開就像真正的 APP 一樣。

---
資料儲存在手機本機（localStorage），不會上傳到網路。
